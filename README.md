# 沿海气象灾害实况预警平台

面向沿海居民、渔民、近海养殖户、沿海商铺、学校和基层应急人员的本地化气象风险信息服务项目。

## 项目文档

- [项目计划书](docs/项目计划书.md)：产品目标、用户需求、功能范围、数据方案、技术架构、实施阶段与风险控制。
- [网页入口](index.html)：沿海气象风险总览的静态演示页面。

## 核心模块

- **台风**：台风名称、中心位置、移动方向与速度、风力信息、官方四级预警、路径地图和分类避险提示。
- **暴雨云团**：云团名称或编号、当前位置、移动方向、雨强、官方暴雨四级预警、雷达实况地图和避险提示。
- **本地风险首页**：在用户授权后定位并匹配所在区县；未授权时提供手动选择，并优先展示当地有效风险。

## 重要原则

- 气象灾害预警信号和级别以有权气象台站发布内容为准；平台展示时保留发布机构、发布时间、有效期和原文链接。
- 云团识别、路径推演和雨强监测属于实况/研判信息，应与官方预警明确区分。
- 页面明确标注数据更新时间、来源和延迟状态；数据不可用或过期时不得继续呈现为最新信息。
- 项目当前处于计划阶段，尚未接入实时数据、地图服务或消息推送。
